# 麻雀レベル++

## サービス概要

「麻雀レベル++」は、麻雀のアガリ形を見て点数を答える問題に繰り返し挑戦し、点数計算を正確かつ素早く行う力を身につける学習サービスです。

点数表を確認して答えを調べるだけではなく、実戦に近い形で「自分で計算して答える」練習の機会を提供します。

## メインターゲット

麻雀の基本ルールと主な役を覚え、アガリ形は理解できるものの、符・翻を含む点数計算にはまだ自信がない人をメインターゲットとします。

特に、友人との対局や雀荘などで点数申告をほかの人や計算ツールに任せており、「自分でもその場で迷わず点数を言えるようになりたい」と考えている人を想定しています。

## ユーザーが抱える課題

点数計算は、解説や早見表を読んで仕組みを理解しても、実際のアガリ形から符・翻・点数をすぐに導き出すには反復練習が必要です。

想定するユーザーは、実際の対局で次のような困りごとを抱えています。

- アガったときに点数計算で手が止まり、対局の進行を待たせてしまう
- 計算に自信がなく、経験者の申告や点数計算ツールに頼ってしまう
- 早見表では個別の点数を確認できても、さまざまなアガリ形を自力で計算する練習がしにくい
- 一人で暗記を続けるだけでは、上達を実感しづらく学習が続かない

これらの結果、点数申告への不安が対局中のストレスとなり、本来の麻雀の楽しさを感じにくくなることが課題だと考えています。

## このサービスの価値・既存手段との差別化

点数早見表や点数計算ツールは、条件を入力して正しい点数を確認する際に便利です。一方、「麻雀レベル++」は答えを調べることではなく、アガリ形を見て自力で点数を導き出す練習に重点を置きます。

- 実際の麻雀牌によるアガリ形を使い、対局に近い形で練習できる
- 10問単位の短い問題形式で、隙間時間に繰り返し挑戦できる
- 正誤だけでなく解説を確認し、間違えた理由を振り返ることができる
- 正解数に加えて回答時間を得点化し、正確さと速さの両方の成長を実感できる
- 得点に応じたランクを設け、次のランクを目指すことを継続の動機にできる

「知識を読む・答えを調べる」段階から、「実戦で使えるように反復する」段階への橋渡しをすることが、このサービス独自の価値です。

## 開発の背景

麻雀は基本ルールや役を覚えると対局を楽しめるようになりますが、点数計算には符計算や翻数、親・子、ツモ・ロンといった複数の条件が関わります。そのため、ルールを覚えた後も点数申告だけは経験者やツールに任せてしまうことが少なくありません。

点数計算を解説する情報や正解を調べる手段はあっても、さまざまなアガリ形を見ながら、自力で素早く答える練習を気軽に繰り返せる場が必要だと考えました。点数申告への不安を小さくし、より自信を持って麻雀を楽しめるようにしたいという思いから、このサービスを開発します。

## MVPで検証したいこと

MVPでは、10問の出題から結果・解説の確認、再挑戦までの体験を提供し、次の仮説を検証します。

1. アガリ形から点数を答える問題形式が、点数計算の練習方法として分かりやすいか
2. 10問という問題数が、負担なく最後まで取り組める量か
3. 正解数・回答時間による得点とランク表示が、再挑戦の動機になるか
4. 問題ごとの解説が、誤答の原因を理解し次の回答に生かす助けになるか

テストユーザーの完了状況・再挑戦の有無と、利用後のヒアリングを通して検証し、難易度、問題数、採点基準、解説内容の改善につなげます。

## MVPの主な機能

- 麻雀の点数計算問題を全10問出題
- アガリ形を麻雀牌で表示
- 3つの選択肢から点数を回答
- 全問回答するまでの時間を計測
- 正解数と回答時間から最終得点を計算
- 最終得点に応じたランクを表示
- 問題ごとの正解と解説を表示
- 再挑戦機能

## アプリの使い方

1. トップ画面の「スタート」ボタンを押します。
2. 表示されたアガリ形と条件を確認します。
3. 正しいと思う点数を3つの選択肢から選びます。
4. 同じ流れで全10問に回答します。
5. 全問回答すると、最終得点とランクが表示されます。
6. 結果画面から、各問題の正解と解説を確認できます。
7. 「もう一度挑戦する」ボタンから再挑戦できます。

## 得点とランク

最終得点は、正解数と回答時間によって決まります。

```text
正解点 = 正解数 × 100
タイムボーナス = floor(1000 × 正答率 × 30,000 ÷ 回答時間(ms))
最終得点 = 正解点 + タイムボーナス
```

- 正解点：1問100点
- タイムボーナス：正答率が高く、回答時間が短いほど多く加点
- 0問正解または回答時間が0ミリ秒の場合：タイムボーナスは0点
- 最終得点：スコアに上限はありません

ランクは、最終得点に応じて次の10段階で判定します。

| ランク | スコア     | レベルの目安                                                               |
| ------ | ---------- | -------------------------------------------------------------------------- |
| SSS    | 1801〜     | 点数申告で卓を止める心配はほぼありません。雀荘でも自信を持ってどうぞ。     |
| SS     | 1601〜1800 | かなりの計算力です。点数表を開くより、あなたに聞く方が早そうです。         |
| S      | 1401〜1600 | 仲間内では頼れる点数係です。たまにはほかの人にも計算させてあげましょう。   |
| A      | 1201〜1400 | よく出るアガリ形なら安定しています。珍しい形でも慌てず計算してみましょう。 |
| B      | 1001〜1200 | 基本的な点数計算は身についています。符が増えたときだけ、少し慎重に。       |
| C      | 801〜1000  | 家族麻雀なら、あなたが点数係を引き受けてあげてください。                   |
| D      | 601〜800   | 点数表があれば心強い段階です。まずはよく出る形から覚えましょう。           |
| E      | 401〜600   | 役と翻は見えてきました。符計算とは、これから仲良くなりましょう。           |
| F      | 201〜400   | 正解より先に選択肢と目が合う時期です。解説を読めば着実に伸びます。         |
| G      | 0〜200     | ここがスタート地点です。伸びしろだけなら、すでにSSSランクです。            |

> ランクと説明は、本サービスのスコアをもとにした習熟度の目安です。
