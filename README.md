# 麻雀レベル++

## サービス概要

「麻雀レベル++」は、麻雀の点数計算を正確かつ素早く行うための学習サービスです。

アガリ形を見て点数を回答する問題に繰り返し挑戦することで、符・翻・役を踏まえた点数計算を身につけることを目的としています。

初心者向けの用語説明だけではなく、麻雀のルールを覚えた初級者が中級者へ、中級者がさらにもう一段上へ進むためのサービスを目指しています。

## 主な機能

- 麻雀の点数計算問題を全10問出題
- アガリ形を麻雀牌で表示
- 3つの選択肢から点数を回答
- 全問回答するまでの時間を計測
- 正解数と回答時間から最終得点を計算
- 最終得点に応じたランクを表示
- 問題ごとの正解と解説を表示
- 再挑戦機能

## アプリの使い方

1. トップ画面の「スタート」ボタンを押します。
2. 表示されたアガリ形と条件を確認します。
3. 正しいと思う点数を3つの選択肢から選びます。
4. 同じ流れで全10問に回答します。
5. 全問回答すると、最終得点とランクが表示されます。
6. 結果画面から、各問題の正解と解説を確認できます。
7. 「もう一度挑戦する」ボタンから再挑戦できます。

## 得点とランク

最終得点は、正解数と回答時間によって決まります。

```text
最終得点 = 正解点 + タイムボーナス
```

- 正解点：1問10点（最大100点）
- タイムボーナス：回答時間に応じて最大100点
- 最終得点：最大200点

ランクは、最終得点に応じて次の10段階で判定します。

| ランク | 評価         |
| ------ | ------------ |
| SSS    | 最高ランク   |
| SS     |              |
| S      |              |
| A      |              |
| B      |              |
| C      |              |
| D      |              |
| E      |              |
| F      |              |
| G      | 最初のランク |

> ランクごとの得点範囲とタイムボーナスの基準は、今後調整予定です。
